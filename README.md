1. Project Overview
AI Career Copilot is a web application that helps users improve their career path using AI-based analysis.
The system analyzes a user's resume, identifies skills, finds missing skills, and suggests a learning roadmap for their desired job role.The goal of this project is to help students and job seekers understand:
->How strong their resume is
->What skills they already have
->What skills they are missing
->What they should learn next
2. Technology Used
Frontend:
React – UI development
Tailwind CSS – Styling
Lucide React – Icons
Chart.js – Graphs and charts
Backend:
Node.js
Express.js
Other Tools:
LocalStorage – storing data
GitHub – project hosting
Vite – fast development environment
3. Application Pages and Features
The system has several pages. Each page performs a specific task.
3.1 Landing Page
-Purpose:The Landing Page is the first page users see when they open the website.
-Features:Introduction to the AI Career Copilot platform
-Overview of features:Call-to-action buttons
-Navigation to other pages
3.2 Resume Upload Page
-Purpose:This page allows users to upload or paste their resume for analysis.
-Features:Resume text input area
-File upload (PDF or text)
-Drag and drop resume upload
-Resume preview
-Analyze button
3.3 Resume Analysis Dashboard
-Purpose:The Dashboard shows detailed results of resume analysis.
-Features:Resume score
-Skills found in resume
-Missing skills
-Resume history
-Score improvement chart
-Dashboard Components
-Resume Score
-Shows a score from 0 to 100.
-Example:Resume Score: 78 / 100
3.4 Career Roadmap Generator
-Purpose:This page generates a learning roadmap for a selected career role.
-Input Options:The user selects:
-Target Role
-Skill Level
-Daily Study Time
-Resume context
Example roles:
Frontend Engineer
Backend Engineer
AI Engineer
Output Generated
The system creates:
Learning Phases
Example:
Phase 1
Learn HTML and CSS
Learn JavaScript basics
Understand web fundamentals
Phase 2
Learn React
Build UI components
Practice API integration
Phase 3
Build portfolio projects
Learn optimization
Prepare for interviews
Action Tasks
The system lists tasks that the user should complete.
Example:
Task 1 – Learn React hooks
Task 2 – Build a portfolio
Task 3 – Practice coding problems
Suggested Projects
Example:
Portfolio Website
E-commerce UI
Weather App
Dashboard Application
Projects help users gain practical experience.
Interview Questions
Example:
Explain React lifecycle.
What is state management?
Describe a project you built.

AI Career Copilot helps users:

7. How to Run the Project
1. Clone the Repository
git clone <your-repo-link>
2. Navigate to Project Folder
cd ai-career-copilot
3. Start Frontend
cd Frontend
npm install
npm run dev
4. Start Backend
cd Backend
npm install
node server.js
